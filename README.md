# TL-C12C-X3用コード

すべての通信は以下の形式で行い、#を終端文字とする。

## 通信プロトコル

```text
cmd,data_len,data,data,data,...#

ex) S,4,1.0,3.0,2.0,1.0#
```

## コントローラー番号について

MotorHandler.cppにある、CONTROLLER_INDEXを変更してください

## ピン配置

- TACH:  Pin 9
- PWM:  Pin 2

## コントローラーが受信するコマンド一覧

※ 返される値が決まっているものは (数値)で示す  
基本的には起動時に初期化設定 (D)→初期化 (I)の順で行う。  
そのまま初期化を行うと初期速度は0になる。

| コマンド | 引数                     | 備考           | 説明                                                                                |
|----------|--------------------------|----------------|-------------------------------------------------------------------------------------|
| S        | -                        | 接続確認       | ステータス確認、`S,データ量(3),デバイス識別番号(0),マイコン番号,ファン接続数`を返す |
| I        | -                        | 回転を初期化   | 初期回転速度に戻し、`I,データ量(0)`を返す                                           |
| D        | ファン番号, 初期回転速度 | 初期化設定     | 初期化した際の回転速度を設定、`D,データ量(2),ファン番号,初期回転速度`を返す         |
| R        | ファン番号, 回転速度     | ファン回転     | ファンの回転速度を変更、`R,データ量(2),ファン番号,回転速度`を返す                   |
| Z        | -                        | 回転停止       | 接続している全てのモーターを停止、`Z,データ量(0)`を返す                             |
| C        | ファン番号               | ステータス確認 | `C,データ量(2),ファン番号,回転速度`を返す                                           |

## エラー出力一覧

| コマンド | コード | 説明               | 発生条件                   |
|----------|--------|--------------------|----------------------------|
| E        | -1     | 初期化未完了       | 初期化されていない         |
| -        | -2     | 無効な速度         | 速度が0未満                |
| -        | -3     | 無効なデータ長     | データ数がデータ長と不一致 |
| -        | -4     | 不明なコマンド     | R,S,P以外のコマンドを送信  |
| -        | -5     | パース不正         | コマンドの形式が不一致     |
| -        | -6     | 無効なモーター番号 | 指定された番号が不明       |
