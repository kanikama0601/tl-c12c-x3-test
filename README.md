# TL-C12C-S X3用コード

Arduino (PlatformIO) で 4pin PWM ファンを制御し、シリアル経由でホストから
回転速度を指示するためのコード。

## 通信仕様

| 項目           | 値                                          |
|----------------|---------------------------------------------|
| ボーレート     | 9600 bps                                    |
| データ形式     | 8bit / パリティなし / ストップビット1 (8N1) |
| 文字コード     | ASCII                                       |
| 終端文字       | `#`                                         |
| 受信フレーム長 | 最大 64 バイト (`#` を含む)                 |

- すべての通信は 1 フレーム = 1 コマンド、または 1 レスポンス。
- `#` を受信した時点でフレーム確定として処理する。`#` の前後の改行 (`CR` / `LF`) は無視する。
- 応答は終端文字 `#` の後に改行 (`CR` + `LF`) を付けて送信する。
- コマンド文字は大文字のみ有効 (小文字は不正コマンド扱い)。
- 区切りの `,` の前後に空白を入れてはならない。
- プロトコル外の平文 (デバッグメッセージ等) はシリアルに出力しない。

## フレーム形式

```text
cmd,data_len,data,data,data,...#

ex) R,2,0,128#     ファン0を duty 128 で回す
    R,2,0,128#     ↑に対する応答 (同じ形式で返る)
```

- `cmd` … コマンド文字 1 文字
- `data_len` … `cmd` と `data_len` を除いたデータの個数。0 の場合はデータ部を持たない (`I,0#`)
- `data` … 10 進整数。小数・符号付きの値は受け付けない (エラーコードのみ負値を取る)

### 値の範囲

| 項目       | 範囲                    | 備考                                  |
|------------|-------------------------|---------------------------------------|
| ファン番号 | 0 ～ (ファン接続数 - 1) | 0 起点。ファン接続数は `S` で取得する |
| 回転速度   | 0 ～ 255                | PWM duty 値。0 = 停止、255 = 最大     |

## ハードウェア仕様

### 対象ファン

Thermalright TL-C12C-S X3 (4pin PWM ファン、コネクタは業界標準の 4-wire 配列)

### ファンコネクタのピン配列

| Fanピン | 信号 | 説明                                  |
|---------|------|---------------------------------------|
| 1       | GND  | グランド                              |
| 2       | +12V | ファン駆動用電源 (+12V)               |
| 3       | TACH | 回転検出信号 (オープンコレクタ出力)   |
| 4       | PWM  | 回転速度制御信号 (25kHz 目安、負論理) |

### Arduino との接続

| Fanピン          | 接続先                          | 備考                                                          |
|------------------|---------------------------------|---------------------------------------------------------------|
| 1 (GND)          | Arduino GND、かつ 12V電源の GND | 3点共通GNDにすること                                          |
| 2 (+12V)         | 外部12V電源の +側               | Arduino の 5V / Vin には接続しない                            |
| 3 (TACH) *未使用 | Arduino D2                      | 外部割込み対応ピン。現在のプロトコルでは未使用                |
| 4 (PWM)          | Arduino D9                      | `analogWrite()` で駆動 (約490Hz、ファン規格の25kHzとは異なる) |

```text
            +----------------------------+
  Fan Pin1 -| GND                        |- Arduino GND
  Fan Pin2 -| +12V   (外部12V電源へ)     |
  Fan Pin3 -| TACH   (未使用)            |- Arduino D2 (未使用)
  Fan Pin4 -| PWM                        |- Arduino D9
            +----------------------------+

  外部12V電源(+) -> Fan Pin2
  外部12V電源(GND) -> Arduino GND / Fan Pin1 と共通
```

### 電源に関する注意

- ファンモーター自体は Arduino の電源 (5V/Vin) からは駆動できない。必ず外部 12V 電源を用意すること。
- Arduino と外部12V電源の GND は必ず共通にすること。共通GNDが無いと TACH/PWM の信号レベルが安定しない。
- ファンの起動電流はモーター停止からの立ち上がり時に定格より大きくなることがあるため、電源側の電流容量に余裕を持たせること。

### PWM 周波数について

4pin ファンの規格上の PWM 周波数は 25kHz だが、`analogWrite()` (Pin 9) は約 490Hz で駆動している。
可聴域に近いため個体によっては動作音が変化する場合がある。25kHz 化する場合は Timer1 を直接設定する必要がある (未実装)。

### TACH (回転数検出) について

Pin3 (TACH) は Arduino D2 に接続する配線を前提としているが、現行のプロトコル (`C` コマンド) は
直近に指示した duty 値を返す仕様であり、実測 RPM を扱うコマンドが無いため、現状のソフトウェアでは未使用。
実測 RPM を返す拡張を行う場合は D2 の外部割込みを使用する。

### ピン配置 (ソフトウェア設定値)

- TACH: Pin 2 (外部割込みが使えるピンであること。現在のプロトコルでは未使用)
- PWM:  Pin 9

## コントローラー番号について

`FanHandler.cpp` にある `CONTROLLER_INDEX` を変更してください。  
この値が `S` コマンドの応答に含まれる「マイコン番号」になります。

## コントローラーが受信するコマンド一覧

※ 応答に含まれる固定値は (数値) で示す  
基本的には起動時に初期化設定 (D)→初期化 (I)の順で行う。  
`D` を行わずに初期化した場合、初期速度は 0 になる。

| コマンド | 引数                     | 初期化 | 備考           | 説明                                                                                |
|----------|--------------------------|--------|----------------|-------------------------------------------------------------------------------------|
| S        | -                        | 不要   | 接続確認       | ステータス確認、`S,データ量(3),デバイス識別番号(0),マイコン番号,ファン接続数`を返す |
| I        | -                        | 不要   | 回転を初期化   | 初期回転速度に戻し、`I,データ量(0)`を返す                                           |
| D        | ファン番号, 初期回転速度 | 不要   | 初期化設定     | 初期化した際の回転速度を設定、`D,データ量(2),ファン番号,初期回転速度`を返す         |
| R        | ファン番号, 回転速度     | 必要   | ファン回転     | ファンの回転速度を変更、`R,データ量(2),ファン番号,回転速度`を返す                   |
| Z        | -                        | 不要   | 回転停止       | 接続している全てのモーターを停止、`Z,データ量(0)`を返す                             |
| C        | ファン番号               | 必要   | ステータス確認 | `C,データ量(2),ファン番号,回転速度`を返す                                           |

- 「初期化」列が「必要」のコマンドは、`I` による初期化前に送るとエラー `-1` を返す。
- `デバイス識別番号` はデバイス種別を表す固定値で、ファンの制御用マイコンは`0`に設定しています。
- `C` が返す「回転速度」は、直近に指示された duty 値 (設定値) であり、TACH による実測 RPM ではない。
- `Z` は全ファンの duty を 0 にする。初期化状態は変化しないため、`R` を送れば即座に再開できる。

## エラー出力一覧

エラー時は要求されたコマンドの応答の代わりに、以下の形式で 1 フレームを返す。

```text
E,1,エラーコード#

ex) E,1,-6#        指定されたファン番号が存在しない
```

| コード | 説明               | 発生条件                                                        |
|--------|--------------------|-----------------------------------------------------------------|
| -1     | 初期化未完了       | 初期化 (`I`) が必要なコマンドを初期化前に送信した               |
| -2     | 無効な速度         | 速度が 0 未満、または 255 を超えている                          |
| -3     | 無効なデータ長     | 実際のデータ数が `data_len` と不一致                            |
| -4     | 不明なコマンド     | `S,I,D,R,Z,C` 以外のコマンドを送信                              |
| -5     | パース不正         | コマンドの形式が不一致 (区切り不正、数値以外の文字を含む)       |
| -6     | 無効なモーター番号 | ファン番号が 0 ～ (ファン接続数 - 1) の範囲外                   |
| -7     | 受信長超過         | `#` を受信しないまま受信フレーム長 (64 バイト) を超えた         |
| -8     | 引数個数不正       | `data_len` は整合しているが、そのコマンドが要求する個数と不一致 |

### 判定順序

複数の条件に該当する場合、以下の順で最初に一致したエラーを返す。

1. `-7` 受信長超過 (この場合、次の `#` までを読み捨てる)
2. `-5` パース不正
3. `-4` 不明なコマンド
4. `-3` 無効なデータ長
5. `-8` 引数個数不正
6. `-1` 初期化未完了
7. `-6` 無効なモーター番号
8. `-2` 無効な速度

## ファイル構成

| ファイル                                   | 役割                                                    |
|--------------------------------------------|---------------------------------------------------------|
| [main.cpp](src/main.cpp)                   | 初期化と `loop()` からの受信処理の呼び出しのみ          |
| [Protocol.h](include/Protocol.h)           | プロトコル定数、エラーコード、フレーム表現              |
| [FrameReader.h](include/FrameReader.h)     | 受信バイト列を `#` 単位のフレームに組み立てる (`-7`)    |
| [CommandParser.h](include/CommandParser.h) | ペイロードの解析とコマンド定義 (`-5` `-4` `-3` `-8`)    |
| [FanHandler.h](include/FanHandler.h)       | 初期化状態・ファン番号・回転速度の管理 (`-1` `-6` `-2`) |
| [PwmFan.h](include/PwmFan.h)               | ファン1台分の PWM 出力                                  |
| [SerialHandler.h](include/SerialHandler.h) | シリアル入出力と上記の橋渡し                            |

ファンを増やす場合は [FanHandler.h](include/FanHandler.h) の `FAN_COUNT` と
[FanHandler.cpp](src/FanHandler.cpp) の `FAN_PWM_PINS` を合わせて変更する (個数が食い違う場合はコンパイルエラーになる)。
